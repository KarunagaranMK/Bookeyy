## Features

### 1. LLM Router

| Provider | Env var | Model var | Notes |
|---|---|---|---|
| **Gemini** | `GEMINI_API_KEY` | `GEMINI_MODEL` | `gemini-1.5-flash` default; JSON via `responseMimeType` |
| **Groq** | `GROQ_API_KEY` | `GROQ_MODEL` | `llama-3.1-70b-versatile`; ultra-fast |
| **OpenRouter** | `OPENROUTER_API_KEY` | `OPENROUTER_MODEL` | 100+ models |
| **Mock** | — | — | Always available; tests |

- **Ordered fallback**: `LLM_PROVIDERS=gemini,groq,openrouter,mock`
- **Retry + backoff**: configurable `LLM_RETRY_PER_PROVIDER` + `LLM_BACKOFF_BASE_S` (doubles each attempt)
- **429/timeout handling**: retryable errors go to next provider after backoff
- **Per-day usage counters**: every successful call recorded in `llm_usage` table (provider + model + tokens_in + tokens_out)
- **No hardcoded model names**: all read from `Settings`

### 2. GeneratedPage Schema

```python
class GeneratedPage(BaseModel):
    course_id, chapter, page, content_version, personalization_hash
    title, narration (Tanglish), word_count
    segments: list[Segment]          # explanation | code | practice | diagram_ref
    diagram: Diagram                 # nodes (bounded 0-800×0-600) + edges + steps
    practice_prompts: list[...]
    analogies: Analogies             # movie + cricket (Tanglish)
    citations: list[Citation]        # chunk_id + document_id + quote
    verified: bool
    verification_errors: list[str]
```

**Validators enforced at parse time** (Pydantic V2):
- ✅ Cue `targetId` must exist in segment IDs or diagram node IDs
- ✅ Diagram edges reference existing nodes (no dangling)
- ✅ Diagram node coordinates within `x:0-800, y:0-600`
- ✅ All segment IDs unique
- ✅ All diagram node IDs unique
- ✅ `word_count` auto-computed from narration if 0

### 3. Generation Pipeline

```
Cache lookup
    ↓ MISS
KB retrieval (B2 RetrievalEngine, top-5 passages)
    ↓
LLM generate_json (attempt 0)
    ↓
Parse + Pydantic validate
    ↓ errors → repair (max 2 more attempts)
Verify (cues / diagram / sandbox / word count / grounding)
    ↓ errors → repair
Persist to generated_pages + page_gen_logs
    ↓
Return GeneratedPage
```

**Cache key**: `sha256(course_id:chapter:page:phash:version)[:32]`  
**Bypass**: `regenerate=True` flag on the generate endpoint

### 4. Code Sandbox

- Runs in **separate subprocess** — never in the FastAPI process
- **5-second hard timeout** (SIGKILL via `asyncio.wait_for`)
- **Network blocked**: safety prefix patches `sys.modules` to replace socket/urllib/httpx/requests
- **Temp dir** created per run, cleaned up on exit
- **Unavailability handling**: if no Python executable, page marked `unverified`; publishing blocked until verified

```python
actual_output, error = await run_code("print(2+2)", "4")
# actual_output = "4", error = None  → code_verified = True
```

### 5. Verification Checks

| Check | Failure | Action |
|---|---|---|
| (a) Cue targets | targetId not found | `verification_errors` + repair |
| (b) Diagram bounds | x>800 or y>600 | Same |
| (b) Dangling edges | from/to missing node | Same |
| (c) Code execution | output mismatch / timeout | Repair → regenerate segment |
| (c) Sandbox unavailable | no Python exec | `sandbox_unavailable=True` → block publish |
| (d) Narration length | < 60 or > 300 words | Repair |
| (e) Citation grounding | chunk_id not in KB | Warning (soft) |

### 6. Admin API Endpoints

| Method | Path | Description |
|---|---|---|
| `POST` | `/api/admin/pages/generate` | Generate (or return cached) one page |
| `POST` | `/api/admin/pages/generate-chapter` | Generate full chapter (SSE progress stream) |
| `GET`  | `/api/admin/pages` | List cached pages (filter by course/chapter/status) |
| `GET`  | `/api/admin/pages/{course}/{ch}/{page}` | Get specific page with content |
| `POST` | `/api/admin/pages/{course}/{ch}/{page}/rollback` | Archive page (un-publish) |
| `GET`  | `/api/admin/pages/usage` | LLM token usage by day/provider |

### 7. Scope Guard

Non-Python courses are rejected immediately with a clear, user-facing error:

```json
{
  "detail": "Course 'javascript' is not supported in B3. Currently only Python courses are generated. Non-Python topics will be supported in a future sprint."
}
```

## Real E2E (Chapter 2, Page 1)

> **Run with a real API key** (`GEMINI_API_KEY=...`) to generate a live page.

```bash
# Set key and generate page
GEMINI_API_KEY=your-key python -c "
import asyncio
from app.page_gen.pipeline import generate_page

async def main():
    page = await generate_page(
        course_id='python',
        chapter=2, page=1,
        chapter_topic='Variables and Data Types',
        page_topic='What is a variable?',
        regenerate=True,
    )
    print('Title:', page.title)
    print('Verified:', page.verified)
    print('Segments:', len(page.segments))
    print('Narration words:', page.word_count)
    print('Diagram nodes:', len(page.diagram.nodes))
    for seg in page.segments:
        if seg.type == 'code':
            print('Code verified:', seg.code_verified)

asyncio.run(main())
"
```
