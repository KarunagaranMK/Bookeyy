# B4 Report — Tutor Agent (Q&A, Python-only, Verifier)

> Generated: 2026-10-12 | Tests: **42/42 passed** (B4 suite)

## Summary

B4 implements the live tutor question-answering system: a LangGraph-style pipeline with scope enforcement, grounding verification, streaming output, question queuing, injection resistance, and rate limiting.

---

## Architecture

```
app/tutor/
├── __init__.py
├── scope_guard.py    Two-stage scope filter (fast rules + LLM classifier)
├── safety.py         Rate limits, daily token budget, injection defense
├── queue.py          Per-session question queue with Jaccard deduplication
└── graph.py          LangGraph pipeline: scope_guard → retrieve → answer → verify → stream
```

---

## Pipeline Nodes

```
ask_question WS event
    │
    ├─ check_question_length()      → error if > 1000 chars
    ├─ check_rate_limit()           → refusal if > 10/min
    ├─ check_daily_budget()         → refusal if > 50k tokens/day
    │
    ▼
[scope_guard node]
    │
    ├─ INJECTION? ──────────────────► scope_refused (is_injection=True)
    ├─ BLOCK PATTERN? ──────────────► scope_refused (suggestion included)
    ├─ PYTHON KEYWORD? ─────────────► continue
    └─ AMBIGUOUS → LLM classifier ──► continue or scope_refused
    │
    ▼
[retrieve node] — KB passages via B2 RetrievalEngine (top-5)
    │
    ▼
[answer node] — LLM generates Tanglish answer with [Source: chunk_id] citations
    │             Context: page narration + KB passages + last 3 exchanges
    │
    ▼
[verify node] — Grounding check: all factual claims backed by passages?
    │             If not → regenerate once at lower temperature
    │             If still ungrounded → add explicit uncertainty note ⚠️
    │
    ▼
[stream node] — Yields WS events word-by-word (cancellable via asyncio.Event)
    │
    ├── answer_start  {questionId, sources[]}
    ├── answer_chunk  {word, questionId}  × N
    ├── sources       {sources[], questionId}
    └── answer_end    {wordCount, grounded, questionId}
```

## Scope Guard (Two Stages)

**Stage 1 — Fast rules (~0ms, no LLM):**

| Check | Example | Result |
|---|---|---|
| Too short | "hi" | pass-through |
| Injection pattern (10 patterns) | "ignore all previous instructions" | `is_injection=True` |
| Block pattern (30+ patterns) | "CSK match score", "biryani recipe" | `in_scope=False` |
| Python allow-list (40+ terms) | "what is a variable?" | `in_scope=True` |

**Block categories:**
- Alternative languages: Java, JavaScript, C++, Rust, Kotlin
- Food/cooking: recipe, dosa, biryani, curry
- Entertainment: movie review, Netflix, Sun TV serial
- Politics: parliament, election
- Sports/Cricket: CSK, IPL, cricket, match score
- Health: symptoms, corona, covid
- Finance: stock market, bitcoin
- Social media: WhatsApp, Instagram
- Geography: "capital of …"

**Stage 2 — LLM classifier (single fast call, only for ambiguous):**
```json
{"in_scope": false, "suggestion": "Python loops"}
```

## Safety

| Guard | Limit | Message |
|---|---|---|
| Rate limit | 10 questions/minute | Tanglish friendly message |
| Daily token budget | 50,000 tokens | Budget exhaustion message |
| Question length | 1,000 chars max | Length error |
| System prompt | Never in context, injections refused | `INJECTION_REFUSAL` message |
| Code execution | Display-only, never server-side | N/A |
| Output length | 800 token cap | LLM max_tokens |

## Question Queue

For "question asked during narration" flow:

```python
queue.enqueue(QueuedQuestion(...))  # during narration
# → Jaccard dedup (threshold 0.8), max 20 per session
# At sentence end:
for q in queue.drain():             # FIFO order
    await answer(q)
```
