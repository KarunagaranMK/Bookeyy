## Known limitations (B1 scope)

- **Scripted tutor answers** — B0 uses keyword-matched scripted replies; B1 connects Gemini/Groq
- **No real TTS** — `audio_chunk` never sent; B1 connects ElevenLabs or Google TTS
- **No real STT** — `audio_in` frames are no-ops; B1 connects Whisper
- **No real code execution** — only seeded examples work; B1 adds a Pyodide Web Worker or sandboxed subprocess
- **Auth is a stub** — all connections are accepted; B1 implements ticket flow
- **No PostgreSQL in dev** — SQLite only; switch DATABASE_URL for production
- **Resume after reconnect** — the frontend sends a narration-level `resume` frame; the server restarts narration from word 0 if no session is found in memory (B1 will persist session state to DB)
